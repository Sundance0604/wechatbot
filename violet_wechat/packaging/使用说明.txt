Violet 0.8.1 · 微信 AI 工作台（Windows x64）

直接使用
1. 将压缩包解压到普通文件夹，双击 Violet.exe，浏览器会打开本地面板。
   无需安装 Python、Conda 或 Node.js。第一次解压启动可能需要稍候。
   新用户默认称呼为 VioletBot，人设和主人资料为空，不附带任何作者账号。
2. 登录电脑版微信。在面板“设置”填写你自己的 DeepSeek API Key。
3. 点击连接微信，添加需要监听的群聊或联系人，再点击“重新连接发送”。
   若工作线程暂未出现，可先在微信中手动发一条文字后重试。
4. 点击“开始监听”才会处理消息。首次默认没有监听群、管理员或项目授权。

目前微信适配范围
支持已验证模块指纹的 4.2.0.11、4.2.0.13、4.2.0.52、4.2.0.53。
不能保证相同版本号的其他构建、其他微信版本或未来更新兼容。
未知模块会拒绝调用发送函数，不会试用旧偏移。
4.2.0.53 已验证读取、发送管理器定位及文字对象构造释放；本次发布未自动发信。
此工具是非官方本机工具，不是腾讯官方接口。

可选项目 Agent
普通 DeepSeek 聊天不要求安装 Agent。
如要使用 /deepseek，另外安装 DeepSeek Harness，在“工作区”的全局 Agent
设置中填写该电脑上的程序路径并启用；模型与 API Key 由使用者自行配置。
如要使用 /agent，另外安装并登录 Codex CLI。
然后自行添加项目目录、绑定群聊及设置权限。程序不会附带原作者的项目或账号。
工作区读写使用 Agent 自己的沙箱；不提供无限制的整机隔离保证。

停止和退出
- 面板“停止全部”：停止监听及 Agent，取消尚未发送的回复。
- “停止监听.cmd”：不用打开浏览器即可发出停止请求。
- “退出程序.cmd”：停止任务并关闭本地服务。
- 关闭浏览器页面不会退出后台服务；再次双击 Violet.exe 会打开已有面板。

配置和日志
默认保存到 %LOCALAPPDATA%\Violet，包含 config.local.json 和 runtime 文件夹。
API Key、聊天上下文、项目任务等数据留在使用者自己的电脑，不在发布包中。
启动日志：%LOCALAPPDATA%\Violet\runtime\launcher.log
API Key 的普通聊天、所选会话上下文会按功能发送给使用者选择的模型服务。
不要把自己的配置文件、runtime、记忆或日志文件夹一起转发给别人。
已有本机设置会保留；更新 EXE 不会删除使用者自行保存的称呼、人设和账号。

离线诊断
Violet.exe --self-test
报告位于 %LOCALAPPDATA%\Violet\runtime\selftest.json，不调用模型、不发送消息。

高级参数
Violet.exe --no-open --port 8767 --data-dir "D:\VioletData"
Violet.exe --quit --data-dir "D:\VioletData"
使用自定义 data-dir 时，停止和退出命令也要带上同一个路径。
